## Important limitation

Automated PCM tests prove determinism, bounds, phase-continuous implementation, and the source pin. They do **not** prove vocal-v1 sounds natural. Manual Windows listening is still required.

The operator's intended acoustic target remains:
- low rumble;
- low-register tonal bird-call character;
- not bright chirps, alarms, whistles, or MIDI-like beeps;
- smooth enough that future human vocal reproduction and microphone recognition remain plausible.

## New product-level finding

A real local-model arithmetic answer transported correctly through EXP-003 but stated an incorrect result. Language transport success is therefore explicitly separate from assistant factual correctness.

Future Rocky personal-assistant work should add validated software-only reasoning/tool boundaries (for example deterministic arithmetic) without allowing the model to bypass Brain/Safety/hardware authority.
