# EXP-003 v0.3 organic vocal renderer direction

Date: 2026-10-05

This revision responds to the second Windows listening pass.

The operator confirmed that EXP-003 timing is now usable and that the lower register is closer to the target, but contour-v1 still sounds too robotic. The desired Chordic sound is a natural low rumble / low-register tonal bird call that remains compositional and recognizable.

## Design change

The semantic token inventory and relative pitch-anchor code are unchanged. v0.3 adds a preferred renderer profile, `vocal-v1`, so acoustic naturalness can improve without changing the language codebook.

`vocal-v1` requires:

- phase-continuous frequency integration through every glide;
- low-register reference near the existing 120 Hz EXP-003 v0.2 baseline;
- a soft glottal/source-filter-like carrier rather than clean independent sine beeps;
- restrained upper harmonics;
- subtle subharmonic body;
- subtle phrase-level amplitude pulse and microprosody;
- deterministic pitch micro-variation no greater than 0.12 semitone so recognition targets remain stable;
- no opaque whole-sentence acoustic IDs.

The intended character is explicitly **natural low rumble / low-register tonal bird call**, not whistle, alarm, MIDI, or bright chirp.

## Default timing

The preferred ordinary-conversation duration multiplier is now **2**. Multiplier 1 remains valid for faster fluent conversation; multiplier 3 remains a learning/debug option rather than the default.

## Translation relationship

Translation scheduling belongs to Rocky rather than Chordic semantics. The desired runtime policy is active overlap: English may start while Chordic is still sounding, but scheduling must target English completion slightly after the Chordic source completes.

## Future natural-carrier experiment

A stronger future path is to keep the same EXP-003 F0 contours while resynthesizing a natural vocal carrier with an offline vocoder or pitch-manipulation backend. That experiment must preserve deterministic semantic timing/contours and remain optional until its licenses, Windows support, latency, offline behavior, and recognition effects are tested.
