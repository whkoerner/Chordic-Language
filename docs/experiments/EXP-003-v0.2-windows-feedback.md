# EXP-003 v0.2 Windows listening feedback

Date: 2026-10-05

Status: manual Windows listening evidence plus deterministic follow-up design. Microphone recognition and human-produced acoustic recognition remain NOT RUN.

## Operator acceptance feedback

The operator confirmed:
- EXP-003 timing is much better than CT2/EXP-002 fallback-heavy playback.
- The lower pitches in EXP-003 and parts of contour-v1 are preferred.
- High-pitch noises are specifically disliked.
- Desired direction: low rumble / low-register tonal bird call rather than bright chirps/beeps.
- contour-v1 is closer to the intended sound.
- The generated English answers are liked.
- English translation should never finish before the source Chordic utterance finishes; translation sequencing should preserve source-before-translation logic.

## Real Windows evidence

### Arithmetic prompt

Prompt: `what is 8 times 8?`

Model reply: `Rocky think. Eight times eight. Sixty four. Yes.`

| profile | Chordic | English | semantic coverage | fallback |
| --- | ---: | ---: | ---: | --- |
| CT2 | 22.38 s | 8.08 s | literal | exact text |
| EXP-002 | 22.31 s | 7.61 s | semantic_tokens=2 | 2 spans / 40 bytes |
| EXP-003 v0.1 | 10.44 s | 7.67 s | 48.6% | 4 spans / 19 bytes |

Pure/resonant/contour-v1 replays of the same EXP-003 representation remained 10.44 s; English measurements were approximately 7.62 s, 8.05 s and 7.68 s respectively.

The important finding is not only the duration improvement. The v0.1 benchmark had used numeric digits, while the real model naturally answered with English number words. That exposed a benchmark coverage gap.

### Food prompt

Prompt: `what is your favorite food?`

Observed CT2 reply:

`Rocky no eat. Rocky learn. Rocky make. Rocky fix. Rocky problem solve.`

- CT2: 29.78 s Chordic / 10.38 s English.

EXP-003 contour-v1 on the same semantic reply:
- 11.97 s Chordic;
- 10.36 s English;
- semantic_tokens=10;
- semantic coverage=77.8%;
- fallback=2 spans / 12 bytes;
- Chordic outlasted English by 0.86 s under the old fixed 0.75 s English lead-in.

The missing concepts were `problem` and `solve`.

## v0.2 semantic response

EXP-003 v0.2 adds:
- compositional spoken-number normalization through 99;
- `ENTITY.PROBLEM`;
- `ACTION.SOLVE`.

No whole-answer IDs are introduced.

The exact arithmetic reply now models as:
`ENTITY.ROCKY MENTAL.THINK NUM.8 OP.MUL NUM.8 NUM.6 NUM.4 SOCIAL.YES`

The exact food reply now models as:
`ENTITY.ROCKY GRAM.NEG ACTION.EAT ENTITY.ROCKY MENTAL.LEARN ENTITY.ROCKY ACTION.MAKE ENTITY.ROCKY ACTION.FIX ENTITY.ROCKY ENTITY.PROBLEM ACTION.SOLVE`

Both regression cases are 100% semantic with zero fallback in the deterministic v0.2 analyzer.

At unchanged 3x timing:
- arithmetic model: 5.58 s;
- food model: 9.30 s.

These are modelled durations, not new Windows measurements.

## v0.2 acoustic response

The original contour structure remains, but the reference synthesis register is lowered:
- semantic reference baseline: 120 Hz;
- semantic five-level range at reference baseline: about 95-151 Hz;
- fallback reference baseline: 105 Hz;
- fallback must use low four-anchor base-5 contours instead of bright multi-octave CT2-style chords;
- recommended output band: 80-180 Hz.

Timbre direction:
- strong fundamental;
- audible but restrained subharmonic body;
- very little second/third harmonic energy;
- subtle low-frequency amplitude pulse;
- small vibrato only.

Goal: a connected low rumble / low-register bird-call-like signal, not a whistle, alarm, MIDI beep sequence, or bright chirp.

## Translation sequencing requirement

The Windows evidence confirms that a fixed 0.75 s English lead-in is logically wrong whenever English finishes before Chordic.

The downstream Rocky v0.2 integration should use a strict source-first policy: English translation may be queued while Chordic renders, but audible English must not begin until the Chordic playback window has completed. This is intentionally conservative. A later duration-aware overlap scheduler may be investigated only if it can preserve the invariant that English never finishes before Chordic.
