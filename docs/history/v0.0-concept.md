# v0.0 — Concept

**Date established:** 2026-10-04  
**Status:** Current experimental language version

## What existed before

The repository began with a single initial commit containing only a one-line `README.md` heading. No phonology, grammar, dictionary, tests, experiments, or licensing structure existed.

## What v0.0 means

v0.0 records the research problem before language rules have been chosen.

The project aims to investigate whether an original tonal communication system can become human-producible, human-learnable, computer-recognizable, compositional, deterministic enough for software, and useful for eventual robotic communication.

## What is defined

- Project name: Chordic Language
- Working language name: Chordic
- Development method: evidence-driven, history-preserving
- Language version: v0.0 — Concept

## What is not defined

- Error-correction strategy: Not yet determined.
- Audio synthesis behavior: Not yet determined.

- Translation behavior: Not yet determined.

## Tests

Not yet tested.

## Known limitations

There is not yet a functioning language. v0.0 exists to make that fact explicit and to preserve the actual starting point for future development.

## Exit criteria

v0.0 should not be left merely because code or documentation was added. Advancing toward v0.1 requires evidence supporting an initial sound inventory/representation and a small set of primitive concepts with machine-readable definitions and tests.
