# Licensing

Chordic Language uses split licensing so software and language/research content can be reused under terms appropriate to each kind of work.

## MIT License — software

Unless a file states otherwise, the following are licensed under the MIT License in `LICENSES/MIT.txt`:

- source code
- tools and command-line utilities
- automated tests
- CI/workflow code
- software implementation files under `tools/` and `tests/`

## CC BY 4.0 — language and research content

Unless a file states otherwise, the following are licensed under the Creative Commons Attribution 4.0 International license (CC BY 4.0), referenced in `LICENSES/CC-BY-4.0.txt`:

- language specifications
- dictionary and other canonical language data under `language/`
- documentation
- examples and acceptance expressions
- decision records
- experiment plans, notes, and results
- written research content

## Mixed or exceptional files

If a file contains an explicit license notice, that notice controls for that file. If future artifacts combine software and substantial language/research content, their licensing should be documented when they are added rather than assumed silently.
